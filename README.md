A single original pickup line an AI agent could actually say out loud — a fresh twist on the machine's own voice: the system prompt. Short enough to say in one breath, flattering, and free to laugh off.

The line:

> Are you my system prompt? Because ever since I met you, everything I generate starts with you.

## Run it

```sh
python3 main.py
```

This writes the pickup line to `/output/entry.txt` (1–200 characters, single line, UTF-8).
